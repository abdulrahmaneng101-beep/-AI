# طريقة التشغيل

1. لازم يبقى عندك Node.js متثبت على جهازك.

2. افتح Terminal في فولدر المشروع وشغل:
   ```
   npm install
   ```

3. اعمل نسخة من ملف `.env.example` وسميها `.env`, وحط فيها مفتاح Resend الحقيقي:
   ```
   RESEND_API_KEY=هنا_المفتاح_بتاعك
   ```
   ⚠️ لازم تعمل regenerate للمفتاح القديم اللي اتبعت في المحادثة قبل ما تستخدمه، عشان بقى مكشوف.

4. شغل السيرفر:
   ```
   npm start
   ```

5. افتح المتصفح على:
   ```
   http://localhost:3000
   ```

## ملاحظة عن الإيميل المرسل منه (from)
Resend بيطلب إن يكون عندك دومين "verified" عشان تبعت من إيميل خاص بيك.
لحد ما تعمل verify لدومين، استخدم `onboarding@resend.dev` كـ from (موجود بالفعل في الكود) وهيوصلك على إيميلك المحدد في `TO_EMAIL`.

لو عايز تبعت من دومين بتاعك، سيب رسالة وهقولك الخطوات.
